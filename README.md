# RanaTech official
🚀 RanaTech – Full Stack Web Application

RanaTech is a full-stack web application developed using Java, Spring Boot, Thymeleaf, Spring Security, and MySQL.
The project serves as a company portfolio and management system with secure authentication and dynamic content handling.

# 🛠️ Tech Stack

▪️Backend: Java, Spring Boot

▪️Frontend: Thymeleaf, HTML, CSS

▪️Security: Spring Security (Authentication & Role-Based Authorization)

▪️Database: MySQL

▪️ORM: JPA / Hibernate

▪️Build Tool: Maven


# ✨ Features

🔐 Secure login and registration system

👤 Role-based access control (Admin/User)

📂 Dynamic content management

🗄️ MySQL database integration

⚡ RESTful architecture

🛡️ Secure backend implementation


# 🔒 Security Implementation

▪️Password encryption using BCrypt

▪️Session-based authentication

▪️Role-based authorization

▪️CSRF protection enabled



# 📌 Future Improvements

Our Projects

Portfolio Website

Built a responsive and professional portfolio website to showcase RanaTech’s services, projects, and team. Designed using Java, Spring Boot, Thymeleaf, and Bootstrap. It includes sections like About Us, Our Services, Projects, and Contact, with smooth navigation and a clean user interface.

User Registration Form

Developed a dynamic user registration form using Spring Boot and Thymeleaf. The form captures user details and stores them securely in a database using MySQL. Implemented form validation, success/failure messages, and seamless integration between frontend and backend.

Second-Hand Car Dealer 🚗

Created a data-driven desktop system using Java and CSV files to manage second-hand car records. The application allows users to view, search, and filter vehicles by brand, model, price, and year. Designed with clean data handling and persistent CSV storage logic.
